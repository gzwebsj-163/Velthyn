# MoCodeDesktop

**MoCode Desktop** — 聊天与智能体管理桌面应用 (macOS)

基于 Electron 构建的桌面客户端，支持聊天对话、智能体管理与 MCP 多服务器系统。

## 技术栈

- **Electron** 28+
- **Node.js**
- macOS 11.0+

## 快速开始

```bash
# 安装依赖
npm install

# 启动应用
npm start
```

## 构建

```bash
# 构建 macOS 应用
npm run build:mac

# 构建所有平台
npm run build:all
```

## 下载

前往 [Releases](https://github.com/mocode/mocode-desktop/releases) 页面下载最新版本。
