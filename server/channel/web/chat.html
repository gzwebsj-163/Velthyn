Mocode Private Crypto Protocol · 协议版本与使用约定

协议概览

组件 名称 职责
APLCE2.0分层加密引擎协议核心，编排全部组件
UTP统一传输协议层协议头封装与校验
OBF混淆层盐异或 + 字节置换
OEM顺序编码映射字符表置换，可逆
HEX十六进制编码二进制与文本互转
UGG全局唯一生成器请求 ID / 盐 / 会话标识
OB对象缓冲dict 与 bytes 序列化
KV键值对编解码元数据载荷
加密 / 解密流水线
加密（APLCE2.0 编排，从左到右）：
UGG 生成ID/盐 → OB 对象序列化 → KV 元数据打包 → OBF 异或+置换 → HEX 十六进制 → OEM 表置换 → UTP 协议头封装
解密（从右到左逆向执行）：
UTP 头校验 → OEM 逆置换 → HEX 解码 → OBF 反混淆 → KV/UGG 校验 → OB 对象还原

字段 示例 说明

架构交付物
架构实例体
PrivateProtocolArchitecture

装配 APLCE2.0 引擎与全部组件，提供 encrypt / decrypt / build_controller。

控制器体
ProtocolController

状态机 INIT→HANDSHAKE→AUTHENTICATED→READY，含握手、认证、校验与会话管理。

OpenAI 桥梁
OpenAIBridge

私有协议加密请求 + X-MP-* 签名头，对接官方 /v1/chat/completions。

使用须知
  1. Mocode-Lab 桥接器 API Key 必须为 mk- 前缀，由 sha256 + md5 + obf 算法生成。
  2. API Key 为空或无效时，浏览器自动化功能将被禁用（桥接配置面板校验）。
  3. 加密流水线：UGG → OB → KV → OBF → HEX → OEM → UTP；解密按逆向执行。
  4. 报文校验含协议魔数、版本、算法链与时间窗（5 分钟）防重放。
  5. OpenAI 官方对接时，私有协议报文作为签名头（X-MP-Protocol / X-MP-Req-Id / X-MP-Sign）随请求发送。
